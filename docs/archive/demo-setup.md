2. **Login:** Go to `http://localhost:8000/dev/skip-login/seller`
3. **Create Listing:** Fill form and submit
4. **Demo Ticket:** Click the demo button in popup
5. **Show Payment:** Open buyer email link
6. **Complete Flow:** Process payment
